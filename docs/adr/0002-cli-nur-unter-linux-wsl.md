# CLI nur noch unter Linux/WSL, Windows bekommt nur die GUI

Unter Windows wird nur noch die installierbare GUI ausgeliefert. Die portable Konsolen-`djsync.exe` entfällt. Die CLI bleibt mit ihrem bisherigen Funktionsumfang für Linux/WSL (Entwicklung) erhalten und bekommt die neuen GUI-Funktionen bewusst nicht (Zurücksetzen auf „offen“, Massenoperationen, Ordnerverwaltung, Umbenennen, Anhören). GUI und CLI teilen sich denselben Kern. Wer also in der CLI eine Funktion vermisst, die die GUI hat, stößt auf eine bewusste Entscheidung und nicht auf ein Versehen.
